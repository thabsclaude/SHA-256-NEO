The reported worst setup path terminates in `miner/hash_engine/core/w_reg[63][29]/D`. Its 166 logic levels include 117 `CARRY4` and 48 `LUT5` elements. This matches the RTL structure: `sha256_compress` expands all 64 schedule words combinationally while loading a block. The result is functionally valid in behavioral simulation but has too much logic between clocked registers for 100 MHz.

## Interpretation

The bitstream and JTAG configuration demonstrate that the project builds and configures the intended device. They do not establish correct 100 MHz execution. A negative setup slack of this size invalidates hash-rate, power, and functional board claims at the requested clock.

The next experiment is architectural, not cosmetic: generate one schedule word per SHA-256 round using a 16-word rolling buffer, then rerun the same test vectors and implementation flow. Only a timing-clean design may become the performance baseline.
